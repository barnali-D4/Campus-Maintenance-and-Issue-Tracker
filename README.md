
# Campus Maintenance & Issue Tracker

A web-based system for reporting, prioritizing, and tracking campus maintenance issues.

## Preview

<img width="1917" height="928" alt="Campus-Tracker-preview" src="https://github.com/user-attachments/assets/820a2025-420d-4554-a5cd-cf3851f21117" />

## Key Features

- Issue reporting and tracking
- Rule-based priority classification: Critical, High, Medium, Low
- Status management: Open, In Progress, Resolved
- PostgreSQL database integration
- Automated testing with Pytest
- Continuous Integration using GitHub Actions
- Containerization with Docker and Docker Compose

## Tech Stack

`Python` · `FastAPI` · `PostgreSQL` · `HTML` · `CSS` · `JavaScript` · `Docker` · `GitHub Actions` · `Pytest`
